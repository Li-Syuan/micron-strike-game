# 美光賺翻了！那我的呢？

一款繁體中文像素職場惡搞遊戲。營收爆發之後，員工爭取加薪、獎金與休假，資方試著維持分配主導權。你可以用上帝視角幫助任何一方。

**[直接開始遊戲](https://li-syuan.github.io/micron-strike-game/)**

- 全滑鼠操作，不需安裝、登入或付費。
- 60 名像素員工、工廠剖面、主管辦公室與談判現場。
- 三種開局情境、八張干預事件卡。
- 勞方勝利、資方勝利、折衷協議、協商未完四種結局。
- 每局約 5～10 分鐘，可暫停或切換兩倍速；離開分頁會自動暫停。

## 怎麼玩

選擇情境，按「公布財報，開演！」。移到事件卡上查看效果，再按下干預局勢。卡片冷卻 20 秒；雙方也會自己應對。只有員工過半接受提案，才會達成協議。

加薪、獎金與休假的改善換算成協商成果：70 分以上為勞方勝利，30 分以下為資方勝利，31～69 分為折衷。8 分鐘最終表決仍未通過則協商未完。

所有人物、財報指數與事件均為架空創作，非真實事件重現，亦非美光官方作品。

## 本機執行

下載此專案後，用 Chrome 或 Edge 開啟 `index.html`。沒有建置步驟或外部套件，音量設定與最近的遊戲結果保存在瀏覽器本機。

程式分為 `engine.js`（規則）、`scene.js`（像素繪圖）及 `app.js`（介面）。
